# Standards texts (reference copies, not redistributed)

The texts live in this folder; git ignores everything here except this index. Each publisher's own copyright terms apply. Grounding's code and docs cite a standard by edition and clause (for example "ISO 14064-3:2019 §6.3") and say what the check does in our own words; the standard's text is never copied into the repo or sent to other AI tools.
